# HireHub 端到端验证

> 完整跑通「注册 → 实名 → 建企业 → 认证 → 发职位 → 投递 → 面试 → Offer」。
> 前置：已按 `docs/第一期运行指南.md` 起好中间件、建好库、启动全部 8 个服务（9000–9007）。

|---|---|

## 角色

- **alice** = 求职者
- **bob** = HR
- **admin** = 平台管理员

所有请求走网关 `http://localhost:9000`。`{TOKEN}` 为各角色登录返回的 accessToken。

---

## ① 求职者 alice：注册 / 实名 / 建简历

```bash
# 注册
curl -X POST http://localhost:9000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"123456","phone":"13800000001"}'

# 登录 → 记下 accessToken
curl -X POST http://localhost:9000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"alice","password":"123456"}'

# 实名（校验位真算法，随便编的号会被拒）
curl -X POST http://localhost:9000/api/auth/real-name \
  -H "Authorization: Bearer {ALICE_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"realName":"李小明","idCard":"110101199003078515"}'

# 建简历 → 记下 resumeId
curl -X POST http://localhost:9000/api/resume \
  -H "Authorization: Bearer {ALICE_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"name":"李小明","phone":"13800000001","expectCity":"杭州","expectPosition":"Java","expectSalaryMin":20000,"expectSalaryMax":35000}'
```

## ② HR bob：注册 / 实名 / 建企业 / 提交认证

```bash
curl -X POST http://localhost:9000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"bob","password":"123456","phone":"13800000002"}'

curl -X POST http://localhost:9000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"bob","password":"123456"}'

curl -X POST http://localhost:9000/api/auth/real-name \
  -H "Authorization: Bearer {BOB_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"realName":"王大壮","idCard":"110101199003078515"}'

# 建企业 → 记下 companyId（创建者自动成为 OWNER）
curl -X POST http://localhost:9000/api/company \
  -H "Authorization: Bearer {BOB_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"name":"某某科技","creditCode":"913100001234567896","industry":"互联网","scale":"100-499人","city":"杭州"}'

# 提交认证（Mock 三要素核验 + 留档，仍待管理员审核）
curl -X POST http://localhost:9000/api/company/{COMPANY_ID}/verify \
  -H "Authorization: Bearer {BOB_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"legalPersonName":"王大壮"}'
```

## ③ 管理员 admin：审核企业通过

```bash
curl -X POST http://localhost:9000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'

# 待审核列表
curl http://localhost:9000/api/company/admin/list \
  -H "Authorization: Bearer {ADMIN_TOKEN}"

# 审核通过
curl -X POST http://localhost:9000/api/company/admin/{COMPANY_ID}/verify \
  -H "Authorization: Bearer {ADMIN_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"approve":true}'
```

## ④ HR bob：发职位（草稿 → 上线）

```bash
# 建草稿 → 记下 jobId
curl -X POST http://localhost:9000/api/job/draft \
  -H "Authorization: Bearer {BOB_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"companyId":{COMPANY_ID},"title":"高级 Java 工程师","skills":"[\"Java\",\"Spring Boot\"]","city":"杭州","salaryMin":25000,"salaryMax":40000,"education":"本科","experience":"3-5年","headcount":2,"jobType":"全职"}'

# 上线（三重校验：实名 + 归属 + 企业已认证）
curl -X POST http://localhost:9000/api/job/{JOB_ID}/publish \
  -H "Authorization: Bearer {BOB_TOKEN}"
```

## ⑤ 求职者 alice：投递

```bash
curl -X POST http://localhost:9000/api/delivery \
  -H "Authorization: Bearer {ALICE_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"jobId":{JOB_ID},"resumeId":{RESUME_ID}}'
```

> 再发一次同样的请求 → 返回**同一个 deliveryId**（幂等，uk(job_id,resume_id) 兜底）。

## ⑥ HR bob：查看投递 → 面试 → Offer

```bash
# 查看收到的投递（需 X-Company-Id）
curl http://localhost:9000/api/delivery/received \
  -H "Authorization: Bearer {BOB_TOKEN}" \
  -H "X-Company-Id: {COMPANY_ID}"

# 发起面试邀约
curl -X POST http://localhost:9000/api/interview \
  -H "Authorization: Bearer {BOB_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"deliveryId":{DELIVERY_ID},"interviewTime":"2026-01-15T10:00:00","interviewType":"线上","interviewerName":"王大壮"}'

# 面试通过 → 发 Offer（状态机：INTERVIEW + SEND_OFFER → OFFER）
curl -X POST http://localhost:9000/api/delivery/{DELIVERY_ID}/events \
  -H "Authorization: Bearer {BOB_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"event":"SEND_OFFER"}'
```

## ⑦ 验证状态机拦截（可选）

```bash
# 非法迁移：PENDING + SEND_OFFER 应该 400（查表得 null）
curl -X POST http://localhost:9000/api/delivery/{DELIVERY_ID}/events \
  -H "Authorization: Bearer {ALICE_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"event":"SEND_OFFER"}'        # alice 是求职者，SEND_OFFER 需要 HR → 403

# 求职者确认 Offer（若走 HIRE 事件需 HR；求职者可 CANCEL）
curl -X POST http://localhost:9000/api/delivery/{DELIVERY_ID}/events \
  -H "Authorization: Bearer {ALICE_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{"event":"CANCEL"}'            # OFFER + CANCEL（求职者拒 Offer）→ CANCELLED
```

## 通过标准

| 环节 | 预期 |
|---|---|
| ① 注册/登录 | `code=0`，登录返回 accessToken |
| ① 实名 | 校验位真算法通过；随便编的身份证号被拒 |
| ② 建企业 | 返回 companyId，创建者成为 OWNER |
| ③ 审核 | admin 通过后 verifyStatus=1 |
| ④ 上线 | 三重校验通过（若跳过实名/未认证则被拦） |
| ⑤ 投递 | 返回 deliveryId；重复投递幂等返回同一 ID |
| ⑥ 面试→Offer | 状态机 PENDING→…→INTERVIEW→OFFER 正常流转 |
| ⑦ 拦截 | 非法事件 400、越权事件 403 |

全部通过即第一期完成。第二期再引入 RabbitMQ（最终一致性）、ES（搜索）、法人授权、Sentinel。
